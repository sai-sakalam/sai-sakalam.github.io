/ research & publications

Published Research

Working in regulated data environments taught me that governance problems are real engineering problems. This research takes one of them — conflicting record-keeping rules across systems — and makes it detectable.

IEEE Access 2026 🔓 Open Access

T-RKG: A Knowledge-Based System for Cross-System Regulatory Conflict Detection in Enterprise Records Governance

Kishore Pulagam, Sai Gavaskar Sakalam

IEEE Access, vol. 14, pp. 138420–138439, 2026 · DOI 10.1109/ACCESS.2026.3729794

Large enterprises keep records across many systems, each governed by its own retention and compliance rules — and those rules can quietly contradict each other. T-RKG models regulations, records and systems as a knowledge graph so these cross-system conflicts can be found automatically instead of during an audit.

🧪 Fully open: the ontology, experiment scripts, tests and results are on GitHub so anyone can reproduce or extend the work.

See the idea in 5 seconds

Illustrative example: one customer, two systems, two regulations.

0 conflictsEach system checks only its own rules, so everything looks fine.

In the repo's composition experiment, splitting the graph per system dropped detected cross-system conflicts to zero on every run. That gap is what T-RKG closes.

pyfirstaid 🩹 first aid for broken Python

"It works on my machine" usually means a broken environment — pip installing into a different Python, SSL errors behind a corporate proxy, a file that shadows the standard library. pyfirstaid runs one command and tells you what is broken and exactly how to fix it.

~/project
$ python -m pyfirstaid
pyfirstaid: checking your Python environment
✔ Python 3.13.1 (supported until October 2029)
✔ Virtual environment active: ~/project/.venv
✘ `pip` installs into a DIFFERENT Python
    fix: use `python -m pip install <package>`
! `random.py` in this folder hides the stdlib module
    fix: rename it, e.g. my_random.py
✔ HTTPS to pypi.org works
✔ 12 compiled package(s) match this Python
✔ No dependency conflicts (pip check)

1 problem(s), 1 warning(s).

Live from PyPI and GitHub

pip install pyfirstaid
  • 12 checks — pip/python mismatch, venv, PATH leaks, SSL, compiled extensions, broken installs, encoding and more
  • Cross-platform — tested in CI on Windows, macOS and Linux, Python 3.9–3.14
  • Works even when pip is broken — a single-file .pyz download runs anywhere
  • Born from the community — started after a discuss.python.org thread advised building it as a package first
